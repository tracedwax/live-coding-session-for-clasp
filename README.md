# Live Coding Session for Clasp

A structured curriculum for teaching Google Apps Script development using Clasp and Windsurf, developed for the Riot Games workshop.

## Structure

```
materials/           # Source materials from stakeholders
  fireside-appsscript/  # Martin's Fireside presentation script + roster
  alteryx-reference/    # Alteryx skills session reference
  datta-reference/      # Paul Datta's Gemini CLI workshop reference
curriculum/          # Final curriculum modules
prework/             # Pre-work instructions for participants
scripts/             # Helper scripts (Clasp setup, etc.)
outputs/             # Workshop outputs, test notes
```

## Workshop Context

- **Audience:** ~15 non-engineer Riot Games employees (no production code experience in 5+ years)
- **Tool Stack:** Windsurf + Gemini model + Clasp CLI + Google Apps Script
- **Primary Use Case:** Automating monthly all-hands slide deck generation from a roster spreadsheet
- **Format:** 1-hour session — icebreaker → Martin demo → hands-on coding in breakout rooms → show & tell
