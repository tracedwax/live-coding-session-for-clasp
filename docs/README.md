# Google Workspace Apps Script + Clasp Workshop

Hands-on enablement for building Google Workspace automations with Apps Script and Clasp, powered by AI-assisted development tools.

> **🛠 Tool-agnostic:** This workshop works with any AI developer tool — [Google Antigravity](https://developers.google.com/gemini), [Windsurf](https://codeium.com/windsurf), [Claude Code](https://claude.ai), [GitHub Copilot](https://github.com/features/copilot), or similar.

## What You'll Build

A Google Apps Script project that **automatically generates a slide deck** from a roster spreadsheet — the same workflow used for monthly all-hands presentations. You'll use Clasp to develop locally and an AI coding assistant to help you write, debug, and iterate.
